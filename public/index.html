How are these numbers calculated?

Tokens, multiplied by an estimated energy cost per token (around 0.0015 Wh from Patterson et al. 2021 and Luccioni et al. 2023), give the compute energy. Cooling water is a separate empirical estimate, around 500 ml per 250 tokens, based on AP News and UC Riverside reporting on data-centre water use.

Both numbers are indicative, not billing-grade. The point is the order of magnitude. CO₂ depends heavily on which grid is powering the data centre. Water is more direct, and lands harder.

How this was built

Accessibility
Every visible text node measured against its effective background across all five pages. 70 WCAG AA failures found, 58 fixed. White prose on the sky measured 2.15:1; near-black on the same sky measures about 9:1, so the first instinct was wrong. The 12 that remain are gold headings carried by a 2px outline the ratio formula cannot see, and are reported rather than "fixed" into something less legible.
Scoring integrity
Scoring runs on the server, so the rubrics and the reference answer never reach the browser — the only way to find out what a level rewards is to attempt it. Two engines sit behind the same endpoint. The one running now is pattern matching, which is instant and free and cannot tell whether an instruction does what a criterion asks, only whether the words are present. The other reads the attempt and has to quote the span of your prompt that earned each point, with the server checking the quote is really there; it is built and switches on with an API key.
Gaming the scorer
Pasting a level's own brief back as the answer used to score 9/10 — across the 45 levels then live, it beat 8/10 on 28 of them. The rubric patterns had been written from each scenario, which made every scenario a near-perfect key for its own rubric. Both engines now ask a prior question — does this text instruct an assistant, or only describe a situation? — and a description lands on Draft however much of the vocabulary it reproduces. Tuned so the errors fall the safe way: it gates none of the 54 reference answers, and catches 48 of the 54 briefs.
