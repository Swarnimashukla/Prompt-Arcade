    How is this calculated?

    Tokens are estimated at ~4 characters per token. Budget is set per scenario based on what a tight, well-specified prompt looks like, not a hard limit. Going over isn't failure, but tokens are a real cost: each one consumes electricity and cooling water in a data centre.

    Energy: ~0.0015 Wh per token (Patterson 2021, Luccioni 2023). Water: ~500 ml per 250 tokens (AP News, UC Riverside). Indicative, not billing-grade.

    How this scoring works
    
    
    Four tiers. One feedback loop.
    
    
    
      
    Draft
    Rubric < 6/10. The prompt is underspecified.
    
      
    Solid
    Rubric ≥ 6/10. Clean pass.
    
      
    Sharp
    Rubric ≥ 7 + under token budget.
    
      
    Surgical
    Rubric ≥ 8 + budget + a responsibility move.
    
    
    
    
    
      How the scoring works, honestly: deterministic pattern matching, run in your browser. Same prompt, same score, every time, with no model involved. That makes it instant and free, and it also means it rewards naming the constraint rather than understanding it. Treat the tier as a prompt-shaped checklist, not a verdict on your thinking.
    
    
    
    
      A responsibility move is anything that prevents downstream harm: a refusal instruction, a citation requirement, a fact-check flag, a privacy/PII guard, or a clear ‘flag if uncertain’. Surgical isn't about word count, it's about whether your prompt would survive a stakeholder review.
